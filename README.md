# מערכת ניהול קליניקה

מערכת מקיפה לניהול קליניקה טיפולית עם תמיכה מלאה בעברית ו-RTL.

## תכונות עיקריות

### 📊 דאשבורד
- מבט כללי על המערכת
- סטטיסטיקות חיות: מטופלים פעילים, פגישות היום, משימות ממתינות
- גרפים וויזואליות

### 👥 ניהול מטופלים
- רשימת מטופלים מלאה
- הוספה, עריכה ומחיקה רכה
- שדות מותאמים אישית
- חיפוש וסינון מתקדמים

### 📅 יומן
- תצוגה יומית/שבועית/חודשית
- ניהול פגישות
- פגישות חוזרות
- התראות ותזכורות

### 💬 מפגשים טיפוליים
- תיעוד מפגשים
- הערות מוצפנות
- נקודות מפתח והמלצות
- ניהול תשלומים

### 📝 דוחות
- יצירת דוחות מהירים
- דוחות מפורטים
- ייצוא ל-TXT/CSV/Excel
- קישור לפגישות

### 📁 קבצים
- העלאת קבצים ומסמכים
- ניהול תיקיות
- חילוץ טקסט מ-PDF
- קישור למטופלים

### ✅ משימות
- ניהול משימות
- עדיפויות וסטטוסים
- שיוך למטופלים
- תזכורות

### 🎯 פעילויות
- מעקב פעילויות
- ניהול תשלומים
- קישור למטופלים

### ⚙️ הגדרות
- ניהול פרופיל משתמש
- תמיכה ב-2FA
- נושאים (בהיר/כהה)
- ניהול הרשאות

## טכנולוגיות

### Frontend
- **React 18** + **TypeScript**
- **Vite** - Build tool מהיר
- **React Router v6** - ניתוב
- **React Query** - ניהול state ו-cache
- **Tailwind CSS** - עיצוב
- **shadcn/ui** - קומפוננטות UI
- **Lucide React** - אייקונים

### Backend
- **Supabase** - Backend as a Service
  - PostgreSQL Database
  - Authentication
  - Storage
  - Row Level Security (RLS)

### אבטחה
- אימות דו-שלבי (2FA)
- הצפנת הערות רגישות
- Row Level Security
- לוג ביקורת מלא
- מחיקה רכה

## התקנה

### דרישות מקדימות
- Node.js 18+
- npm או yarn

### שלבי התקנה

1. שכפל את הפרויקט:
```bash
git clone <repository-url>
cd Clint1963
```

2. התקן תלויות:
```bash
npm install
```

3. הגדר משתני סביבה:
```bash
cp .env.example .env
```

ערוך את `.env` והוסף את פרטי Supabase שלך:
```
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

4. הרץ את סביבת הפיתוח:
```bash
npm run dev
```

5. בנה לייצור:
```bash
npm run build
```

## סכמת בסיס הנתונים

### טבלאות עיקריות
- `users` - משתמשי מערכת
- `profiles` - פרופילי משתמשים
- `patients` - מטופלים
- `sessions` - מפגשים טיפוליים
- `appointments` - פגישות מתוכננות

- `reports` - דוחות

- `activities` - פעילויות

- `audit_log` - לוג ביקורת

## תפקידים במערכת

- **admin** - גישה מלאה לכל המערכת
- **therapist** - מטפל - גישה למטופלים, מפגשים, דוחות
- **supervisor** - מפקח - צפייה וניהול
- **receptionist** - פקיד קבלה - ניהול פגישות ויומן
- **billing** - חשבות - ניהול תשלומים
