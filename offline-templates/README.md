# מערכת תבניות מקומית - Offline Template System

מערכת מאגר תבניות מצגות המיועדת לעבודה על מחשבים ללא חיבור לאינטרנט.

## תכונות עיקריות

- **עבודה ללא אינטרנט** - כל הקבצים מקומיים, אין תלות בשרתים חיצוניים
- **כתובות יחסיות** - עובד מכל מיקום בכונן, ללא צורך בנתיבים קבועים
- **עיצוב מודרני** - ממשק נקי ומקצועי בעברית (RTL)
- **חיפוש מהיר** - חיפוש תבניות לפי שם, תיאור או תגיות
- **הרחבה קלה** - הוספת תבניות חדשות ללא שינוי קוד

## מבנה התיקיות

```
offline-templates/
├── index.html              # עמוד הבית הראשי
```

## הוראות שימוש

### פתיחת המערכת
1. העתיקו את התיקייה `offline-templates` למחשב
2. פתחו את קובץ `index.html` בדפדפן (לחיצה כפולה)
3. זהו! המערכת תטען אוטומטית

### חיפוש תבניות
- הקלידו בשדה החיפוש מילת מפתח
- המערכת מחפשת בשם, תיאור ותגיות
- לחצו ESC לניקוי החיפוש

### הורדת תבנית
- לחצו על כפתור "הורד" בכרטיס התבנית
- הקובץ יורד ישירות מהתיקייה המקומית

---

## הוספת תבנית חדשה

### שלב 1: הוספת קבצים
1. **קובץ המצגת**: העתיקו את קובץ ה-PPTX/PDF לתיקיית `templates/`
2. **תמונת תצוגה**: העתיקו תמונת preview לתיקיית `previews/`
   - מומלץ: SVG, PNG או JPG
   - רזולוציה מומלצת: 1920x1080 או 16:9

### שלב 2: עדכון קובץ ה-JSON
פתחו את `config/templates.json` והוסיפו רשומה חדשה:

```json
{
  "id": "template-004",
  "name": "שם התבנית בעברית",
  "description": "תיאור קצר של התבנית ומה היא כוללת",
  "file": "שם-הקובץ.pptx",
  "preview": "שם-תמונת-preview.svg",
  "format": "pptx",
  "badge": "חדש",
  "tags": ["תגית1", "תגית2", "תגית3"],
  "slides": 10,
  "aspectRatio": "16:9"
}
```

### שדות חובה:
| שדה | תיאור |
|-----|-------|
| `id` | מזהה ייחודי לתבנית |
| `name` | שם התבנית להצגה |
| `file` | שם קובץ המצגת (בתיקיית templates/) |
| `preview` | שם קובץ התמונה (בתיקיית previews/) |

### שדות אופציונליים:
| שדה | תיאור |
|-----|-------|
| `description` | תיאור מפורט |
| `format` | סוג הקובץ (pptx/pdf) |
| `badge` | תווית מיוחדת (למשל: "חדש", "מומלץ") |
| `tags` | מערך תגיות לחיפוש |
| `slides` | מספר שקפים |
| `aspectRatio` | יחס תצוגה |

### שלב 3: רענון
רעננו את הדף (F5) - התבנית החדשה תופיע אוטומטית!

## הסבר טכני: כתובות יחסיות

### למה כתובות יחסיות?
המערכת משתמשת **אך ורק** בכתובות יחסיות (Relative Paths), למשל:
- `templates/file.pptx` ✅
- `./assets/css/styles.css` ✅
- `C:\Users\...` ❌
- `/absolute/path/...` ❌

### היתרונות:
1. **גמישות מיקום** - עובד מכל תיקייה בכל כונן
2. **העברה קלה** - פשוט העתיקו את התיקייה
3. **ללא הגדרות** - לא צריך לשנות שום דבר
4. **תאימות** - עובד על כל מחשב Windows

### איך זה עובד?
כשהדפדפן פותח את `index.html`, הוא מחפש קבצים **יחסית למיקום של index.html**:
```
index.html נמצא ב: D:\Templates\offline-templates\
אז הדפדפן מחפש:
- D:\Templates\offline-templates\assets\css\styles.css
- D:\Templates\offline-templates\templates\file.pptx
```

## פתרון בעיות

### התבניות לא נטענות
- וודאו שקובץ `config/templates.json` קיים ותקין
- בדקו שאין שגיאות ב-JSON (פסיקים, מרכאות)
- פתחו את Developer Tools (F12) ובדקו שגיאות בקונסול

### תמונה לא מופיעה
- וודאו ששם הקובץ ב-JSON זהה לשם הקובץ בתיקיית `previews/`
- שימו לב לרישיות (case-sensitive)
- וודאו שהתמונה בפורמט נתמך (SVG, PNG, JPG)

### קובץ לא יורד
- וודאו ששם הקובץ ב-JSON זהה לשם הקובץ בתיקיית `templates/`
- בדקו שהקובץ קיים בתיקייה
